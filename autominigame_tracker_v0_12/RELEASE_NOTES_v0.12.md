# Auto Minigame Tracker v0.12.0

## 主要修复
- 初始目标过滤：限制目标框占比、相对尺寸、锚点邻域和枢轴邻域。
- 稳定质心枢轴：质心轨道半径不足时允许稳健固定质心作为旋转枢轴。
- 相邻帧轮廓增量匹配：首次全角度校准，后续小角度搜索。
- 渐隐末端单扇区救援：要求当前光流足够切向、低离散度，并与近期实测角速度一致。
- 背景波动隔离：目标边缘和邻接背景环角流接近时拒绝输出。
- CSRT 重置后持续几何兜底：只在当前帧几何证据有效时返回点位，不携带旧 bbox。
- 局部 Farneback 降采样到 0.75 倍，位移矢量恢复原始像素尺度。

当前验证容器使用 OpenCV 4.13.0，但没有 CSRT API。Follower 级回放不等于真实 CSRT 测试；本版本尚未完成 Windows 实机窗口捕获、CSRT 精度和鼠标注入闭环验收。请在 Windows 环境安装 `requirements.txt` 后进行实机验收。
