# 自动化小游戏程序 — 渐隐旋转图形跟踪 0.12.0


## 0.12.0：渐隐跟踪续接、背景误流抑制与生命周期修复

本版本针对 v0.11 回放中发现的三类问题进行修正：初始倒计时/高亮组件可能污染几何种子；累计旋转后单帧模板角度匹配容易产生歧义；CSRT 达到自身丢失上限并重置后，Follower 可能提前结束几何兜底。

- **目标种子过滤**：按画面占比、初始目标框面积比例、初始锚点邻域和拟合枢轴邻域过滤小型倒计时字形、开始文字及尺寸不一致的组件。
- **稳定质心枢轴**：当旋转图形质心近似固定、圆弧半径不足以可靠拟合时，使用多帧稳健质心作为枢轴，避免因小半径轨迹被拒绝而无法测角。
- **相邻帧增量角度**：首次可见匹配对种子轮廓做全角度搜索；之后比较相邻有效轮廓并限制在小角度增量范围，避免累计旋转后的模板匹配歧义。
- **渐隐末端单扇区救援**：当只剩一段轮廓弧时，要求该段当前光流具有足够样本、低离散度、强切向性，并与近期实测角速度同向且接近。
- **背景环对照**：实时渐隐测角时，将预测目标边缘角流与邻接背景环比较；若背景也出现近似角流，则拒绝输出，降低背景波纹造成的伪跟踪。
- **证据时间刷新**：每次当前帧残余边缘测量成功后刷新证据时间；运行时允许短暂的间歇弱流帧，但没有新鲜有效证据仍会停止输出。
- **CSRT 重置后继续几何兜底**：CSRT 超过自身丢失帧数并重置后，只要独立几何跟踪器尚未 LOST 且当前帧证据有效，就继续输出几何点；不再附带过期 CSRT bbox。
- **局部光流降采样**：Farneback 在 0.75 倍局部图像上计算，再恢复原始位移尺度，减少渐隐阶段的计算量。
- 新增 Follower 级录像回放工具 `tools/benchmark_follower_replay.py`，用于验证外观跟踪器失效与几何兜底的状态机交接。

## 0.11.0：实时旋转几何兜底与自适应背景流场

0.10.0 的旋转枢轴、可见轮廓角度和渐隐残余光流此前仍是独立离线分析。本版本把这套几何状态接入 `WhiteFigureFollower`，并保留 CSRT 为主要外观跟踪通道。

- **可见阶段校准**：持续累积白色目标质心圆弧，稳健拟合旋转枢轴；通过局部角度模板匹配更新旋转方向和角度。
- **CSRT 正常时低成本同步**：用 CSRT 当前帧点位同步几何角度，并推进光流参考帧，不在每个正常帧重复执行稠密光流。
- **CSRT 失效时几何兜底**：只有枢轴、旋转方向、局部残余流和时序一致性均通过门限，且置信度不低于 0.55，才允许输出几何备用点。
- **冲突停止**：如果最近 100 ms 内有高置信度几何结果，而 CSRT 点与几何点相差超过动态门限，则停止输出坐标，避免错误移动鼠标。
- **跨轮次隔离**：完全丢失后重新捕获新目标时重置旧几何轨道，避免把上一轮枢轴带入下一轮。
- **自适应背景模型**：对周围背景环带分别验证二次与三次局部流场，只有三次模型在留出样本上明显改善时才启用；每 8 次拟合复核一次模型阶数。
- **局部计算**：稠密光流和轮廓角速度计算限制在目标及周围环带，减少全屏计算。

## 0.10.0：残余边缘空间一致性与 UI 误检隔离

0.9.0 已能在原始录像渐隐阶段获得局部残余光流，但单一全局中位角速度可能被背景某一处波浪边缘带偏；另外，目标附近出现的“开始”字样可能被当成白色残片，错误刷新渐隐观察计时。

0.10.0 对这两个问题做了针对性处理：

- **四象限残边投票**：把预测轮廓附近的残余光流按旋转枢轴划分为四个空间象限，分别估计角速度。优先要求多个分离区域方向/速度一致，降低单处背景波峰劫持整体角度的风险。
- **有条件的时序救援**：渐隐末期只剩两处残边时，允许在至少两个角区域同向、整体角速度接近最近可靠角速度中位数、残差离散度合格时继续更新。纯背景平移即使给定历史角速度先验也必须被拒绝。
- **UI 文本隔离**：旋转枢轴建立后，白色候选质心若偏离目标质心轨道超过默认 18 px，就从目标观测中剔除；此类组件不再刷新目标渐隐计时。
- **逐帧诊断**：CSV 增加空间扇区数量、一致性比例、是否使用时序救援、偏离轨道候选拒绝标记。
- 保留 0.9.0 的局部背景二次流场、切向残余光流和失败保护；没有足够证据时仍不输出新位置，不做匀速外推。

## 0.9.0：渐隐阶段的时序连续性与局部运动放行

0.8.0 的测试发现：`DualMotionEstimator.valid` 代表“整个残余区域是否能被一个全局相似变换解释”，它不等于“目标轮廓附近是否存在可用的旋转证据”。当背景波浪占据大部分 ROI 时，全局拟合会判为弱旋转，但局部轮廓的切向残余光流仍然清晰。0.9.0 修正了这个错误的前置门控。

- **局部流独立判定**：背景拟合成功后，即使全局相似变换不通过，也保留残余光流交给预测轮廓边缘角速度估计器单独判断。
- **渐隐时序一致性**：使用最近 5 次可靠角度增量的中位数作为短期参考；方向反转或角度增量偏离过大时拒绝该帧。
- **渐隐噪声容忍**：空间光流 MAD 门限放宽，并使用指数型一致性评分；时序方向和角度连续性承担主要误报抑制。
- **弱可见证据续接**：完整轮廓匹配失败时，只要局部白色目标残片仍被检测到，就刷新渐隐观察窗口，继续尝试局部光流。
- **证据超时停止**：最后一次检测到目标残片后超过 0.25 秒仍无新的可见证据，或连续 4 帧流证据不足，则锁定 LOST。必须重新匹配到清晰轮廓才可重新启动。
- 不使用恒速外推；完全消失后的背景运动不会被当作目标轨迹。

- 目标残片证据消失后，追踪器按超时/连续失败规则停止，不继续跟随背景波浪。

## 0.8.0：旋转枢轴与渐隐阶段独立运动分析

本版本针对原始视频中“目标自身旋转、背景同时波浪形变”的双运动特征新增离线算法：

1. **可见阶段枢轴估计**：对每帧白色目标连通区域求质心。非对称图形绕固定点旋转时，质心绕旋转枢轴形成圆弧；用 RANSAC 圆拟合估计枢轴，而不是把目标矩形框中心当成运动中心。
2. **可见阶段角度测量**：以最初清晰轮廓为模板，在枢轴附近做旋转模板匹配。匹配分数或角度区分度不足时拒绝输出。
3. **渐隐阶段角度更新**：使用 `DualMotionEstimator` 在目标框周围拟合局部二次背景光流场，扣除背景波浪形变；只在预测轮廓边缘附近提取残余光流，并使用绕枢轴的切向分量估计角度增量。
4. **失效保护**：残余流不连贯、角速度反向、角度跳变过大或连续四帧证据不足时停止更新。新的高置信度可见轮廓重新匹配后才重新启用。没有使用匀速外推。

- `validation/rotation_geometry.csv`：逐帧检测、枢轴、角度来源和状态。
- `validation/rotation_geometry.json`：汇总结果。

- **全场重捕获**：首次初始化仍限制在中央出生区域；跟踪启动后，白色目标重捕获范围扩展到整个游戏客户区。
- **容错阈值**：活动跟踪期间允许使用较低亮度/较高饱和度的白色候选进行校正；不会用容错候选初始化新目标。
- **鼠标轨迹叠加**：预览中红点为目标安全点、绿圈为实际鼠标位置、黄色线为鼠标轨迹；显示 CSRT 丢失帧数与目标/鼠标距离。
- **CSV 会话日志**：逐帧记录状态、目标框、目标点、鼠标点、误差、CSRT 分数、轮次事件和帧率。
- **事件截图**：检测到成功/失败时保存截图。
- **配置持久化**：窗口标题、FPS、自动跟随、事件识别、OCR、丢失容忍帧数和初始化确认帧数自动保存。

## 核心算法

1. 中央区域近白色 HSV 分割，按面积、宽高比、填充率和形状评分筛选目标。
2. 用距离变换寻找轮廓内部安全点，避免鼠标点落在不规则形状外缘。
3. 连续多帧确认后初始化 OpenCV CSRT（HOG + Color Names、padding=2.0、template_size=200）。
4. 图形渐隐时，CSRT 根据每一帧的新图像更新外观/相关滤波模型；**不使用匀速历史轨迹外推**。
5. 图形重新显现时，使用严格/容错分割候选和当前跟踪框做空间关联，再重新校正跟踪器。
6. 跟踪器失效时不输出过期坐标；超过丢失帧数后进入 LOST，等待图形重新出现。
7. 成功/失败提示用模板多尺度匹配，连续确认后触发；Tesseract 是可选兜底。

如果目标在若干帧内完全不可见，且画面中没有可供关联的外观/上下文线索，任何纯视觉算法都不能保证知道真实位置。本程序在跟踪器报告失效时停止发送鼠标坐标，不会伪造位置。

## 0.7.0：背景波浪运动与目标独立旋转分离

新版本不再把整块图像的光流视为目标轨迹。针对背景自身会波浪式拉伸/扭曲、目标边缘却相对背景继续旋转的现象，增加独立视觉诊断器：

1. 对相邻帧计算稠密反向光流。
2. 在目标 ROI 外围环带拟合局部二次背景流场，以近似背景的非刚性波浪形变。
3. 从 ROI 内实际光流扣除拟合的背景流，保留目标相对背景的残余流。
4. 在残余边缘运动上用 RANSAC 拟合相似变换，得到独立旋转角、相对平移和拟合置信度。
5. 当残余边缘不足或拟合不一致时，明确标记无效，不再使用旧坐标或背景坐标代替。

离线分析命令：

```powershell
python tools/analyze_dual_motion.py source.mp4 --seed-time 1.0 --end-time 3.6 --bbox 330,215,80,80 --out dual_motion.mp4 --csv dual_motion.csv
```

`rotation_center` 目前只作为诊断量：在用户提供的压缩录像上仍有明显抖动，未达到直接驱动定位的精度，因此没有接入实时鼠标控制。该模块当前属于离线实验，不代表已完成实时渐隐目标跟踪。
