# 冒险岛小游戏助手

Windows 桌面程序，针对你提供的小游戏画面流程实现：识别白色移动图形、在图形变淡时利用时间前景和运动预测保持鼠标跟随；检测“成功”提示后寻找结果框确认按钮，点击后继续监控下一轮。

## 使用

1. Windows 10/11 安装 Python 3.11。
2. 在项目目录运行：

```powershell
pip install -r requirements.txt
python app.py
```

3. 进入小游戏前启动程序，点击“开始监控”。
4. 默认启用鼠标跟随和成功后的自动确认；可随时关闭自动流程或点击停止。

## 识别逻辑

- 高亮低饱和度掩膜用于获取白色目标。
- MOG2 时间背景模型用于捕捉移动、逐渐变淡的图形。
- 卡尔曼滤波在短暂无可见特征时预测目标中心。
- 成功横幅出现后切换到结果框状态，找到橙色确认按钮并点击；结果框消失后恢复下一轮监控。

## 构建 Windows EXE

GitHub Actions 会自动运行测试并打包。打开仓库的 **Actions**，选择最新成功的 **Windows build**，从 **Artifacts** 下载 `WhiteTargetAssistant-windows`。

## 当前限制

当前识别核心使用 OpenCV CPU。此版本尚未集成 CUDA 推理，也没有在真实冒险岛客户端中完成端到端验证。目标完全不可见且运动方向突变时，单靠屏幕画面无法保证预测正确。成功横幅和橙色按钮检测是基于你提供的截图颜色特征，仍需在实际游戏分辨率下验证。

不解密第三方软件、不绕过保护机制；这是独立实现。
