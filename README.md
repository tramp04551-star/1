# 冒险岛小游戏助手

> 当前仓库中的旧版 Python 跟踪器仅为原型，不是最终验收版本。透明阶段预测、真实窗口捕获和结果对话框确认尚未达到交付标准。

## V2 技术基线

- [V2 核心架构与验收规范](docs/ARCHITECTURE_V2.md)
- 以用户提供的原始软件说明、两轮 1,550 张截图、录屏和测试记录作为回归基准。
- 主检测采用 ONNX 分割模型；Windows GPU 推理采用 DirectML，覆盖 NVIDIA / AMD / Intel，并保留 CPU 回退。
- 捕获使用独立 WGC worker，DXGI 仅在系统明确不支持 WGC 时作为兼容后端。
- 跟踪融合分割、低透明度图像证据、LK 光流、背景运动补偿和 IMM 多运动模型；不再使用单一恒速外推冒充透明阶段跟踪。
- 游戏完成流程分为成功横幅、结果对话框、确认按钮检测、点击和关闭复检；不会点击成功文字中心。

## 构建纪律

最终 Windows 包必须从仓库中唯一、可审查的源代码直接构建。隐藏的 base64 源码包不能继续作为 CI 的实际输入。每个包必须绑定 commit SHA、测试报告和依赖清单。

## 当前状态

尚未通过目标私服客户端实机验收的功能不会标记为“已完成”。旧版包不要作为自动跟踪和自动确认的最终版本使用。
